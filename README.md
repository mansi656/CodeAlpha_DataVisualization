# Task 3 — Data Visualization

## Goal
Turn the dataset into charts that make patterns easier to understand.

## Run
```bash
python Task3_Data_Visualization/create_visualizations.py
```

The script uses live scraped data if Task 1 has run; otherwise it uses the included sample dataset. Charts are saved as PNG files in `output/`.

## Charts generated
1. Average price by category (bar chart)
2. Rating distribution (bar chart)
3. Price distribution (histogram)
4. Price versus rating (scatter plot, if those columns exist)

## What to explain
A chart should answer a question. Read the title, axes and units before interpreting it. Do not claim that one factor causes another just because two values appear related.
